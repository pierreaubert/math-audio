# math-autodiff Code Review — 2026-08-18

Scope: full review of `crates/math-autodiff/src/` (21 files) for correctness bugs
(gradient/adjoint math, edge cases, panics, numerical stability) and performance
issues. Six parallel reviews by module group: core plumbing (lib/module/gradient/
error/tensor), FFT layer + signals, LTI blocks (gain/delay/matrix), IIR
(biquad/sos/response), IIR (peq/geq/svf), and composition/loss/optim
(recursion/system/loss/optim).

## Bugs

### Medium

1. **Panic on non-contiguous single-channel FFT input** —
   `src/fft.rs:294-297, 503-508`. The `channels == 1` fast paths call
   `as_slice().expect(...)` on user-supplied tensors; any non-standard-layout
   view (reversed axes, strided slice of shape `(batch, nfft, 1)`) panics
   instead of returning `AutodiffError`.
   Fix: fall back to the elementwise path when `as_slice()` is `None`.

2. **Sigmoid saturation → exact 0 or Nyquist cutoff → 0/0 NaN** —
   `src/iir/biquad.rs:42-44, 599-625`. `sigmoid(x)` rounds to exactly 0.0/1.0
   for extreme raw params (Adam can push params there even with vanishing
   gradients). At `fc = fs/2` a lowpass gives `num = den = 0` at the Nyquist
   bin → NaN in forward and gradient; `fc1 = 0` in bandpass → `sinh(inf)` →
   NaN coefficients. Every sibling clamps physical params (`svf.rs:82-89`,
   `geq.rs:131`, `peq.rs:90-101`); `biquad.rs` is the only one without the
   guard.
   Fix: clamp `fc_norm` to `[1e-6, 1-1e-6]` after the sigmoid.

3. **`ParallelDelay::backward` missing shape validation → reachable panic** —
   `src/delay.rs:372-421`. It never checks `n_channels`/`n_bins` against
   `self`, then indexes `self.param[[ch]]` (line 398) with the *input's*
   channel count — index-out-of-bounds panic instead of `Err`.
   `Delay::backward` does this check; this one doesn't.

### Low

4. **Dead, type-inconsistent gradient abstraction** — `src/gradient.rs:6-26`.
   `Gradient<T>`/`Parameters<T>` use complex gradients, have zero consumers
   workspace-wide, and are incompatible with the live `DiffModule`
   real-gradient convention. Anyone copying the pattern produces inconsistent
   adjoints. Delete or wire up.

5. **`Delay`/`Matrix` trust `self.n_out`/`n_in` against the `pub param`
   field** — `delay.rs:191-193`, `matrix.rs:231-233`. Replacing `param` with a
   smaller tensor panics; `Gain` derives loop bounds from `param.dim()`
   instead — match that.

6. **`sos_response` panics on shape mismatch where siblings return `Result`** —
   `src/iir/response.rs:175-179`. Also, the raw-pointer code in
   `sos_coefficient_vjp_with_basis` (`response.rs:229-292`) assumes identical
   b/a layouts enforced only by `debug_assert!` — sound today, fragile in
   release.

7. **`SosFilter` has no pole-stability handling** — `sos_filter.rs:60-70`. Raw
   coefficients are learned directly; a denominator root on the unit circle
   gives inf/NaN. The math stays "correct" but it's a behavioral cliff vs the
   unconditionally-stable RBJ parameterization. Confirm it is deliberate.

8. **`WhiteNoise` broadcasts one draw to all channels** —
   `src/signals.rs:117-125` — all channels perfectly correlated, and
   inconsistent with `VelvetNoise` in the same file. If unintended, move the
   draw inside the channel loop; it can mask per-channel gradient bugs in
   tests.

9. **Negative `raw` delay gets exactly zero gradient** — `delay.rs:51-53` —
   the optimizer can never recover a delay parameter once it goes negative.
   Appears deliberate but is one-sided; confirm intent.

## Performance

### Highest impact (hot loop, every training step)

1. **`SosFilter::backward` materializes O(K²·M·N) Jacobians when an O(K·M)
   VJP already exists** — `sos_filter.rs:230-279` → `response.rs:479-571`. It
   builds `other_response` with per-section "product over all others" loops
   plus two `Array5` Jacobians, only to contract them against `dl_dh`.
   `sos_coefficient_vjp_with_basis` (`response.rs:199`) computes the identical
   result in O(K·M·N) and is already used by `Biquad::backward`. Since
   `ParametricEq`, `GraphicEq`, and `SvFilter` backwards all delegate here,
   this one fix speeds up every PEQ/GEQ/SVF step.

2. **`ParallelBiquad::backward` computes the full response twice** —
   `biquad.rs:1286-1288`: `sos_frequency_response_parallel` then
   `sos_frequency_response_jacobian_parallel` re-runs everything including
   `h`. One `sos_response` call (or the VJP) suffices.

3. **`Series::backward` / `Parallel::backward` re-run the entire forward
   pass** — `system.rs:97-103, 239-240` — doubling forward cost per step,
   plus a full-tensor `.clone()` per module. Fix needs either a trait change
   or caching the last forward (the pattern `Recursion` already uses with
   `response_cache`).

4. **`Matrix` (Orthogonal) backward: 2n² matrix exponentials per call** —
   `matrix.rs:284-299`. A single 2n×2n block-triangular exponential (Higham's
   Fréchet block trick) gives an *exact* gradient in one exp — replacing
   O(n⁵)-ish work and removing the finite-difference error.

5. **`delay_response` rebuilt every forward and backward** —
   `delay.rs:194, 236, 362, 401` — n_out·n_in·n_bins trig evals, twice per
   step, with identical arguments. Cache keyed on a param-version counter (the
   `Biquad` `work_*`/`param_hash` pattern is the established idiom), and
   replace the per-(pair, bin) `mapv` temp allocations with zipped in-place
   accumulation.

### Moderate (per-call)

6. **realfft allocates fresh scratch on every `process()`** — `src/fft.rs`
   (8 call sites). Extend the existing thread-local `FFT_BUFFER_CACHE` with a
   scratch buffer and use `process_with_scratch` — removes an O(nfft) heap
   allocation per FFT in the exact loops the cache was built for.

7. **`Biquad::backward` clones the whole coefficient cache per call** —
   `biquad.rs:860-868` (four array clones just to satisfy the borrow checker;
   use `std::mem::take` and put it back). Also: `ParallelBiquad` has no
   coefficient cache at all (`biquad.rs:1211, 1284`) — give it the same
   hash-keyed cache as `Biquad`.

8. **Per-forward dead clone of the inner `SosFilter`** — `peq.rs:328-332`,
   `geq.rs:200-204`, `svf.rs:439` — ~120 KB copied and discarded per forward
   for a 10-section × 8-channel config. Construct fresh instead.

### Small

9. `optim.rs:48` — temp array per parameter per step; use `Zip::for_each`
   in-place. `loss.rs:56` — two full-tensor allocations for
   `(pred − target) * scale`; fuse with `azip!`. `recursion.rs:598` — full
   gradient-tensor clone per backward; `recursion.rs:247-285` — O(n_params)
   fingerprint hashing per call (version counter would be O(1)).
   `gain.rs:454, 464` / `matrix.rs:236, 308` — avoidable `mapv` temps in
   fallback paths. `fft.rs:98-104` — fresh `RealFftPlanner` per module
   instance (cold path; consider a plan cache keyed on nfft).
   `fft.rs:569-585, 362-371` — backward passes lack the `channels == 1`
   contiguous-slice fast path that forward has.

## Verified clean

The risky math checks out — worth stating explicitly since these are the
places bugs would be silent:

- **FFT adjoints** (rfft interior-bin 0.5 weighting, DC/Nyquist real-only
  handling, 1/N absorption in irfft adjoint, odd-nfft grids) — derived
  independently and confirmed by the existing finite-difference tests at
  nfft ∈ {15, 16}.
- **SOS/biquad rational-function Jacobians** — signs, denominator powers,
  conjugation, zero-numerator fallback path, and the reversed-cutoff bandpass
  gradient routing are all correct.
- **SVF (TPT) transfer functions** — all 8 filter types match
  `math-iir-fir::SvfFilter` exactly, including shelf pre-warp and peak
  denominator conventions; PEQ/GEQ match math-iir-fir's RBJ conventions by
  construction.
- **Feedback composition adjoint** (`recursion.rs:523-543`) — solved
  *exactly* via per-bin `(I−H_fb)⁻¹` inversion (no iterative truncation), and
  the `AᴴG` / `Aᴴ G H_ffᴴ Aᴴ` adjoints are correct.
- **Factor-of-2 convention** — `loss.rs` returns `2·∂L/∂conj(pred)` while
  modules accumulate `Re(Σ g·conj(x))` without the 2; the two conventions
  compose correctly end-to-end (verified by derivation and FD tests).
- **`validate_spectral_gradient_shape`** (`module.rs:6-31`) — rank, per-axis,
  and channel-axis exemption logic correct at all 11 call sites.
- Anti-alias envelope adjoints, sweep/velvet-noise/exp-decay signal math,
  softplus clamp/derivative consistency, `Magnitude::backward` real-axis
  projection, SGD parameter/gradient ordering across all compositions.

## Suggested priority

Cheap real correctness fixes first: bugs #2 (sigmoid NaN) and #3
(ParallelDelay panic). For performance, #1 (SosFilter VJP) is the single
biggest win and the infrastructure already exists; #4 (orthogonal matrix
block-exponential) is the most elegant.
